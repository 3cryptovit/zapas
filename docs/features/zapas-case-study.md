## Контекст и цель

Лендинг рассказывал о продукте. Для портфолио нужно ещё два ответа:
как это работает внутри и как это делалось. Человек, открывший
`/zapas/`, должен за пять минут увидеть и продукт, и инженерную
работу за ним.

## Решения

- Новый раздел «Как я это делал» — шесть классов ошибок, по одному
  настоящему случаю в каждом, и цифры из измерений. Ссылки на журнал,
  `process.md` и ADR — на каталоги и файлы, а не на номера строк.
- Схема устройства — inline SVG: CSP не пускает внешние картинки, а
  SVG в разметке не скрипт. На телефоне схема прокручивается внутри
  своей рамки, а не сжимается до нечитаемого шрифта.
- Точность — медиана свежих демо (85%) с оговоркой про 77% после недели
  без заказов: честнее, чем одна красивая цифра.

## Что пошло не так

- **«86% точность на демо-данных» была цифрой из ТЗ**, где она стоит
  как пример формулировки. Измерено — 85% (5 демо, 190 позиций) и 77%
  на демо, промотанном неделю без заказов. Класс D.
- **Горизонтальная прокрутка на телефоне была и до этой задачи**: `<pre>`
  со сводкой Telegram раздвигал колонку сетки на 100 px. Найдено
  измерением правых границ элементов, а не на глаз.
- **Первая версия схемы врала стрелками**: выходило, что Redis
  отправляет в Telegram, а API вызывает воркер. Перерисовано по коду:
  API берёт из Redis лимиты, воркер — задачи, в Telegram отправляет
  только воркер из outbox.
