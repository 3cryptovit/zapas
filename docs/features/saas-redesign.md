# Фича: редизайн под B2B SaaS

Кабинет и страница-кейс на `/zapas/` переводятся из монохромной
издательской эстетики в спокойный интерфейс рабочего инструмента.
Портфолио (`D:\vitalness`) не трогается.

> Статус: готово, на проде с 2026-09-28 10:24 UTC
> Оценка: 8 ч · Факт: 7 ч

## Контекст и цель

ТЗ дизайнера: современный B2B SaaS для малого бизнеса. Приоритет —
читаемость, потом иерархия, порядок, эстетика, декор. Главное правило:
«сначала убрать всё лишнее, потом тщательно расставить акценты».

Это разворот предыдущего решения. [monochrome-redesign](monochrome-redesign.md)
по требованию владельца убрал цвет совсем и кодировал статус штриховкой.
Новое ТЗ возвращает цвет, но дозированно: один спокойный акцент на всё
и приглушённые статусы только там, где они помогают ориентироваться.

Что меняется по сути, а не по оттенку:

| Было | Стало |
|---|---|
| Прописные с трекингом в заголовках, кнопках и навигации | Обычный регистр, иерархия размером и начертанием |
| Прямые углы, волосяные линейки | Радиус 12 px у карточек, 8 px у кнопок и полей |
| Верхняя навигация табами | Компактная боковая панель с линейными иконками |
| Статус — штриховка, подпись, вес | Статус — приглушённый цвет, точка, подпись |
| Системный Helvetica | Inter, свой хостинг, табличные цифры |
| Акцент — чёрный | Один спокойный синий |

## Крайние случаи

| Случай | Ответ |
|---|---|
| Пять статусов рядом | Различаются подписью и точкой; «Закончилось» и «Критично» оба красные, но первое — сплошной заливкой, второе — мягкой |
| Дальтонизм и ч/б печать | Подпись остаётся всегда, цвет — второй канал, не единственный |
| Экран 360 px | Боковая панель уходит в выдвижное меню, таблицы — в карточки |
| Контраст | Каждая пара «текст — фон» ≥ 4,5:1, считается формулой, а не на глаз |
| Длинное название позиции | Переносится, не раздвигает таблицу |
| Пустые состояния | Нет позиций, нет уведомлений, нет заказов |
| Панель демо и пошаговое демо | Не перекрывают контент, умещаются на телефоне |
| Графики | Факт, прогноз, коридор, исключённые дни различимы без тяжёлой сетки |
| Шрифт не загрузился | Системный стек в запасе, вёрстка не едет |

## Решения

**Токены, а не правка оттенков по месту.** Шкалы `slate`, `brand`,
`red`, `amber`, `emerald` заданы в `@theme` заново, приглушённые. Каждая
пара «текст — фон» посчитана формулой WCAG, минимум 4,5:1: основная
кнопка 5,71:1, подписи на подложке 4,52:1.

**Inter — два файла из семи.** Латиница и кириллица, 67 КБ. Подключены
своим `@font-face`, а не общим CSS пакета: иначе Vite положил бы на
сервер и греческий, и вьетнамский.

**Статус — плашка, точка и подпись.** Подпись есть всегда, поэтому цвет
остаётся вторым каналом: дальтонизм и ч/б печать не теряют смысла.
«Закончилось» — единственная сплошная плашка на экране.

**Боковая панель 240 px, на телефоне — выдвижное меню.** Активный пункт
— мягкий синий фон, а не заливка.

**Страница-кейс — на тех же токенах.** Текст не менялся: все цифры на
ней выверены в [zapas-case-study](zapas-case-study.md). Чёрные секции
заменены светлыми, штриховой макет дашборда — HTML-макетом в стиле
кабинета.

**Модальное окно — через портал.** Оверлей с `position: fixed` внутри
трансформированного предка позиционируется от предка, а не от окна.

**`/me` отдаёт `autopilot`.** Без этого переключатель показывал
«выключен» после перезагрузки при работающем автопилоте.

## Что пошло не так

Шесть старых дефектов и три моих, все найдены на стенде в браузере, не
тестами. Подробно — в [дневнике](../journal.md), запись «редизайн,
который нашёл шесть старых багов».

| Что | Класс | Чем закрыто |
|---|---|---|
| `crypto.randomUUID is not a function` вне HTTPS и в Safari < 15.4 | A | Запасной путь через `getRandomValues`, тест `api.test.ts` |
| Карточка заказа и пересчёта не обновлялась после действия | C | Инвалидация `['order']` и `['count']`, тест `queries.test.tsx`, проверен мутацией |
| «поставка … (сегодня)» при любой дате | E | Сравнение с «сегодня» организации |
| «10.000» в поле приёмки | E | `inputQty`, тест в `format.test.ts` |
| Переключатель автопилота врал после перезагрузки | B | Поле `autopilot` в `/me`, проверено живым запросом |
| Линия страхового запаса за пределами оси | B | `ifOverflow="extendDomain"` |
| `w-full` и `w-28` в одном `class` | F | `withWidth` в `ui.tsx` |
| Глобальные правила вне `@layer` перебивали утилиты | F | `@layer base` |
| Диалог открывался посреди страницы | B | Портал и `animation-fill-mode: backwards`, проверка в сценарии |

## Как проверил

| Что | Результат |
|---|---|
| `tsc`, `eslint`, `vitest` | чисто, 40 тестов |
| Go: `gofmt`, `vet`, `go test -race` | чисто, 15 пакетов |
| `redocly lint` | контракт валиден |
| Стенд: nginx с путями прода, API, PostgreSQL, Redis в Docker | 37 снимков Playwright на 1440 и 390 px, ноль ошибок консоли и сети, диалог целиком в экране |
| Кейс | ширина без прокрутки на обеих ширинах, Inter загружен |
| Выкат | смоук: страницы, скрипты, стили и все четыре файла шрифта `200 font/woff2` |
| Прод в браузере | кейс → демо → дашборд → карточка на обеих ширинах, ноль ошибок консоли и CSP, текст набран Inter |

Смоук выката теперь проверяет и шрифты: они подключаются из CSS, а не из
HTML, и их пропажа — тихий откат на системный шрифт.
